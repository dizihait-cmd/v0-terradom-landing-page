# TerraDom — Статическая версия сайта

Это полностью статическая версия сайта, готовая к деплою на любой хостинг.

## Структура папки

```
static-site/
├── index.html          # Главная страница
├── 404.html            # Страница ошибки
├── images/             # Изображения сайта
│   ├── hero-house.jpg  # Главное фото
│   ├── house-1.jpg     # Проект дома 1
│   ├── house-2.jpg     # Проект дома 2
│   ├── house-3.jpg     # Проект дома 3
│   ├── case-1.jpg      # Кейс 1
│   └── case-2.jpg      # Кейс 2
├── _next/              # CSS, JS и шрифты (не трогать!)
│   └── static/
│       ├── chunks/     # JavaScript и CSS файлы
│       └── media/      # Шрифты
└── *.png, *.svg        # Иконки и фавиконки
```

## Как задеплоить

### Вариант 1: Vercel (бесплатно, рекомендуется)

1. Перетащите папку `static-site` на https://vercel.com/new
2. Готово! Сайт будет доступен по ссылке.

### Вариант 2: Netlify (бесплатно)

1. Перетащите папку `static-site` на https://app.netlify.com/drop
2. Готово!

### Вариант 3: GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите содержимое папки `static-site` в корень репо
3. Settings → Pages → Source: Deploy from branch → main
4. Готово!

### Вариант 4: Любой хостинг

Загрузите содержимое папки `static-site` в корневую директорию хостинга.

## Как изменить контент

### Изменить изображения

Замените файлы в папке `images/` на свои изображения с теми же именами:
- `hero-house.jpg` — главное фото на первом экране (рекомендуется 1920x1080)
- `house-1.jpg`, `house-2.jpg`, `house-3.jpg` — фото проектов (рекомендуется 800x600)
- `case-1.jpg`, `case-2.jpg` — фото кейсов (рекомендуется 600x400)

### Изменить текст, телефоны, email

Откройте `index.html` в текстовом редакторе и используйте поиск/замену (Ctrl+H):

| Найти | Заменить на |
|-------|-------------|
| `+7 (843) 200-00-00` | Ваш телефон |
| `+78432000000` | Ваш телефон без пробелов |
| `info@terradom.ru` | Ваш email |
| `г. Казань, ул. Баумана, 1` | Ваш адрес |
| `TerraDom` | Название вашей компании |
| `Казань` | Ваш город |

### Настроить EmailJS (отправка заявок)

Найдите в `index.html` следующие строки и замените значения:

```
YOUR_SERVICE_ID    → ваш Service ID из EmailJS
YOUR_TEMPLATE_ID   → ваш Template ID из EmailJS
YOUR_PUBLIC_KEY    → ваш Public Key из EmailJS
```

Как получить ключи — читайте в инструкции SETUP-GUIDE.md основного проекта.

## Важно!

- **Не переименовывайте и не удаляйте папку `_next/`** — там находятся стили и скрипты
- **Не меняйте структуру папок** — ссылки на файлы заданы жёстко
- **Сохраняйте имена файлов изображений** — просто заменяйте содержимое

## Проверка локально

Откройте `index.html` в браузере двойным кликом или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .
```

Затем откройте http://localhost:8000
